# Definition of Done (DoD) – Kasir Pet Solution (POS Turbo V1)

1. Semua migrasi dapat dijalankan di mesin baru tanpa error.
2. Seeder awal menghasilkan minimal:
   - 1 akun admin
   - 2 kategori
   - 2 satuan
3. Transaksi penjualan: scan barcode → item masuk keranjang <200ms.
4. Struk tercetak benar di printer thermal 58/80mm.
5. Laporan harian sesuai dengan perhitungan manual sampel.
